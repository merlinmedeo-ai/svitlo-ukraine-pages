Конфіденційність

Щоб показати власнику його канали, сервіс зберігає технічний Telegram ID власника, ідентифікатор і назву каналу та права, надані боту.

Для особистих сповіщень сервіс зберігає Telegram ID користувача, обрану область, стан сповіщень і підтвердження разової оплати. Ці дані потрібні, щоб надіслати новий або змінений графік у приватний чат із ботом.

Щоб власник бота бачив загальну статистику, сервіс фіксує Telegram ID та час запуску /start, відкриття Mini App і перегляду графіка. У статистиці показуються лише підсумкові кількості без імен та ID користувачів.

Для оплати зберігаються код рахунку, кількість Telegram Stars, час прийняття умов і ідентифікатор транзакції Telegram. Дані платіжної картки бот не отримує.

Оголошення зберігається окремо для кожного каналу і показується через посилання цього каналу. Графіки для відвідувачів безплатні.

Питання щодо даних і платежів: @SvitloUkrainePower.
